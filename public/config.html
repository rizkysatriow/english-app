☁️ Akses via Cloudflare Tunnel

  1. Install cloudflared dari halaman download Cloudflare (Windows: file .msi).
  2. Pastikan server Node jalan (npm run dev).
  3. Jalankan perintah ini di terminal baru:
cloudflared tunnel --url http://localhost:3000
  1. cloudflared akan menampilkan URL seperti https://xxx.trycloudflare.com — buka URL itu di HP/browser mana pun.
  2. Tempel URL tersebut ke kolom PUBLIC_URL di atas lalu Simpan, supaya API tidak diblokir CORS.
  3. URL quick tunnel berubah tiap cloudflared di-restart. Untuk URL tetap, buat Named Tunnel + route di dashboard Cloudflare Zero Trust.
